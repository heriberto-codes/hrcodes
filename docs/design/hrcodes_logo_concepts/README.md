# HRCodes logo concepts

Three exploratory logo directions using the portfolio palette:

- `hrcodes-geometric.png`: geometric intertwined H/R/C monogram
- `hrcodes-hand-drawn.png`: expressive hand-drawn intertwined H/R/C monogram
- `hrcodes-hand-drawn-r-extension-c.png`: revised hand-drawn concept where the coral C grows directly from the R
- `hrcodes-hand-drawn-parallel-terminals.png`: revised concept with the C and R terminals moving down-right in parallel
- `hrcodes-ultra-minimal.png`: reduced monoline intertwined H/R/C monogram
- `hrcodes-second-sketch-replica.png`: refined interpretation of the second sketch with a shared H/R junction and bold coral C stroke

Palette:

- Deep navy: `#192A51`
- Coral: `#F29576`
- Warm cream: `#F9E9D5`
- Muted blue-gray: `#8893AF`

These PNG files are design explorations. The selected direction should be redrawn as precise SVG artwork before replacing the production logo.
